The logo files contain outlined artwork, not live text, so the font does not need to be installed to use
them. It is only needed to rebuild the files with `build.sh`, or to set brand typography (Inter Display for
headlines, Inter for text).

The Os in the logo are custom geometry built for MORE POWER; they are not glyphs from Inter.

Wordmark settings: size 120 units, tracking +35/1000 em, word space 0.24 em, OpenType kerning on, Os
optically fitted (70 % of their extra width distributed as side space).
